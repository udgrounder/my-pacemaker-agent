# 공통 방법론 계획의 적용 범위와 원천 프로젝트 사례 분리
**타입**: 방법론 개선
**발견 상황**: 공통 질문·가정 관리 계획을 작성하면서 범위·제외 범위와 검증 기준에 원천 프로젝트의 수수료·배분 사례를 그대로 포함했고 사용자가 정정했다.
**적용 범위**: 모든 프로젝트

## 현재 방식
이슈의 출처 사례를 공통 적용 범위·제외 범위·검증 요건에 재사용하여 방법론 변경이 특정 업무에 종속된 것으로 읽힐 수 있었다.

## 개선 방안
공통 방법론 계획은 역할·행동·판단 기준으로 범위와 검증 요건을 일반화한다. 프로젝트 식별자와 업무 사례는 필요한 출처·발견 근거로 구분한다. 계획 점검 시 원천 사례가 공통 적용 조건으로 남았는지 확인한다.
