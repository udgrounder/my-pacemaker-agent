## 조용한 결정과 가정 검증

- **의도적 설계 반영.** 직접 허용 관계와 설치별 JSON 정책을 선택하고 정책 부재 시 안전 상속/직접 실행으로 제한했다. 순차 인계는 구현 분할 없이 기존 아키텍처와 양립한다.
- **구현에서 정한 세부 값.** 선택적 활성 상한 2명은 호스트 전체 고정 한도가 아니라 별도의 보수적 예산이다. 단순 탐색에 허용 하위 후보가 여럿일 때 `preferred`의 하위 후보 순서는 모델 ID 정렬이며 등급 근거는 아니다. `preferred`는 선호 신호이고 최종 `selected`는 확인된 해당 호출을 의미한다.
- **가정 유효.** Codex 우선·다른 호스트 안전 축소, 직접 허용 목록, 설치별 정책, 추론 수준 상한과 단일 구현 인계가 지침·코드에 대응한다. 추론 및 실제 설정 증명 가용성은 호스트별 미확인 범위다.
- **가정 부분 충족.** 최초 근거가 유지된 입력에서 창 모델을 낮추거나 비교 불가 모델로 바꾸면 실행 중 교집합 밖 대상과 실제 모델 미확인 대상이 중단·미확인 목록에 들어간다. 수정본은 고정한 시작 근거와 다른 현재 관찰을 최초 근거로 받는 경우를 거부한다. 최초 근거의 실제 출처를 확보하고 작업 기록에 보존하는 책임은 메인에게 있다.
