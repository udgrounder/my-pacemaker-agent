# 제한된 에이전트 위임 독립 재검토

## 대상과 근거

`task_documents.py inputs <task>/plan.md --stage review1`이 반환한 승인해시 `reqspec-v1:3e7fcc16cac22f14`의 명세와 설계 발췌를 기준으로 검토했다. 실제 판단은 `.mpa/runtime/`의 `hooks/agent_policy.py`, `core/agent_rules.md`, `inject/agent_delegation.md`, `inject/_agent_execution_priority.md`, `inject/layer1_{design,implement,critique,review}.md`, `inject/task_documents.md`와 해당 dist 파일, 지정 테스트 3종, `docs/agent-delegation.md`, `agent-specs/codex/spec.md`에 근거한다. 발췌에 포함된 실행 주장과 체크 표시는 검증 증거에서 제외했다.

## 검토 결과

### 즉시 수정 필요

- **minor 완료 승인 위임 충돌.** `.mpa/runtime/core/agent_rules.md:124`는 사용자 또는 위임 에이전트의 확인 뒤 done 처리를 지시한다. `.mpa/runtime/inject/layer1_implement.md:131-136`의 동일 분기는 위임 에이전트의 확인을 받아 `완료 승인`, INDEX 제거, done 이동까지 이어진다. 승인 명세의 완료·승인 권한 보존과 `inject/agent_delegation.md:24`, `inject/task_documents.md:76`의 사용자 완료 확인 조건에 충돌한다. 두 지침에서 위임 에이전트의 검증 증거와 사용자 완료 승인을 구분하고, 완료 승인·INDEX 변경·이동을 사용자 완료 확인 뒤에만 수행하도록 정합성을 회복해야 한다. 지정 source와 dist에 같은 문구가 존재한다.

### 주의 필요

- **슬롯 부족이 확인 불가 경로를 가린다.** `.mpa/runtime/hooks/agent_policy.py:230-233`은 `free_slots=0`과 현재 모델 증거 누락을 함께 전달하면 선택 탐색과 필수 검증에 모두 `wait/no_slot`을 반환한다. 슬롯이 생기면 같은 입력에서 탐색은 `direct`, 검증은 `review_self_check`다. `inject/agent_delegation.md:9`와 `inject/_agent_execution_priority.md:28-33`이 명시한 확인 불가 처리가 지연된다. 현재 호출의 증거·설정이 유효한 경우에 슬롯 대기를 적용하는 조건으로 검토할 수 있다.
- **1차 입력에 실행 주장이 섞인다.** 실제 `inputs --stage review1`은 승인된 검증 체크리스트의 체크 상태와 “읽기 전용 실행 결과를 확인했으며 실제 모델 ID는 미확인이다”를 출력한다. 실행·완료 주장을 배제하는 `inject/layer1_review.md:7`의 목적과 충돌하고, 이후 입력 격리를 판단할 때 완료 편향을 유발할 수 있다. 승인된 원본과 해시를 보존하면서 1차용 입력에는 기준 문구만 제공하도록 확인할 필요가 있다. 이 문장으로 호스트 실행이나 모델 ID를 판정하지 않았다.

### 정합성 확인

- **정상 경로.** 간단한 탐색에서 검증된 직접 하위와 역할별 가용 목록이 일치하면 `select/lower`다. 설계는 현재 메인 모델을 선호하며 해당 모델의 확인된 명시 호출이 통과한다. 설치 정책이 없을 때에도 안전한 상속 증거가 있으면 `inherit/main`이다. 이익이 불충분한 탐색은 `direct`다.
- **실패 경로.** 전이 관계만 있는 모델과 비교 불가 모델을 거부했다. 세션·역할·호스트·revision·출처·시각이 틀린 증거나 누락된 최초 기록은 호출을 승인하지 않았다. 상속 증거의 명시 호출 전용 재사용, 사용자 역할 설정의 모델 덮어쓰기, 추론 수준 불일치와 미지원도 거부했다. 같은 revision에서 메인 모델 증거가 충돌하면 종료 코드 2와 `invalid`를 반환했다.
- **모델 전환.** 더 높은 창 모델로 바꿔도 최초 직접 허용 집합과의 교집합은 확대되지 않았다. 낮추면 허용 범위 밖이거나 모델 미상인 실행의 ID를 `stop_and_mark_unconfirmed`로 반환했다. 이 값은 중단 지시의 근거다. 실제 중단 효과는 호스트 증거가 필요하다.
- **순차 인계와 독립 실행.** `agent_delegation.md:19-24`와 `layer1_implement.md:5`에서 메인의 쓰기 중단, 전체 구현을 한 담당자에게 인계, 종료·결과 대조 후 메인 회수를 명시한다. 도구 입력의 `sole_writer=false` 및 `by_main=false`를 거부하는 경계를 확인했다. 파일별 쓰기 경쟁 방지와 인계 완료는 절차 지침에 근거하며 실제 동시 쓰기·회수 상황은 미확인이다. `layer1_design.md`, `layer1_critique.md`, `layer1_review.md`, `task_documents.md`와 공통 실행 규칙에 필수 비평, 대화 미상속, 검증 1·2차의 순서, 미완료 시 비평 생략 확인과 검증 자가 검증이 남아 있다. 증거가 없는 필수 역할의 각 분기와 격리 불가 검증을 CLI에서도 확인했다.
- **복구.** 하위 탐색 실패 뒤 현재 메인 모델로의 첫 복구는 통과했고, 이미 1회를 사용한 입력은 `direct/recovery_budget`이었다. 호출 오류와 산출물 누락의 처리 및 산출물 판정은 공통 지침에서 확인했다. 호스트 실패나 산출물 누락을 실제 요청으로 유발하지 않았다.

### 조용한 결정

- 선택적 동시 활성 수 2명과 복구 1회는 승인 발췌의 제한 방향을 구체화한 운영 판단이다. 문서에 명시되어 있고 실제 슬롯이 더 적으면 호스트 슬롯을 따르는 경계를 확인했다.
- 증거 최신성은 세션 및 revision의 효력 시각을 기준으로 판단한다. 호출자가 신뢰 가능한 최신 revision과 증거를 제공하는 전제는 지침에 명시돼 있다. 도구는 이 입력의 일관성을 검사하며, 호스트에서 확인한 사실이나 현재 상태를 직접 취득하지 않는다.
