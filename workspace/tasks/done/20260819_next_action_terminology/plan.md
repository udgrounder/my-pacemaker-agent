### 범위·제외 범위

- 범위: `다음 작업 예측` 관련 지침·주입 문서·사용자 대면 문구의 의미를 조사하고, 확정된 용어로 정렬한다.
- 제외 범위: 기존 완료 태스크의 plan.md 형식·승인해시를 변환하지 않으며, 태스크 생명주기나 계획 승인 체계 자체를 변경하지 않는다.

### 완료 기준

용어의 의미와 적용 대상이 사용자 결정으로 확정되고, 관련 지침·문구가 그 결정과 일치하며, 구형 태스크의 이력은 변경 없이 보존된다.

### 사용자 결정

`다음 작업 예측`을 `다음 행동 제안`으로 바꾼다. 태스크 생성뿐 아니라 검증 시작·재구현·중단 같은 일반 행동도 제안한다는 실제 의미를 사용자 대면 용어에 반영한다. (사용자 승인: 2026-08-19)

### 변경 불가 제약

구형 태스크와 done 이력은 최신 형식으로 자동 변환하지 않는다. 실제 사용자 행동의 자유를 제한하는 새 승인 절차를 추가하지 않는다.
