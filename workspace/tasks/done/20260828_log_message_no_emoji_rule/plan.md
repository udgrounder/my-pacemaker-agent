# 작업 계획서: 소스 로그 메시지 이모지 금지 기본 규칙

**파생 출처:** 없음

---

## 요구사항 명세

### 요청 기준

소스 코드가 남기는 로그는 재처리될 수 있으므로, 로그 메시지에 이모지·이모티콘을 사용하지 않도록 기본 Runtime 규칙에 추가해 달라는 요청이다. 매 수정마다 별도 소스 검사를 실행하는 방식은 이번 범위에서 제외한다.

### 목적

향후 MPA를 사용하는 에이전트가 소스 로그를 새로 추가하거나 수정할 때 재처리 호환성을 해치는 이모지·이모티콘을 넣지 않게 한다.

### 범위·제외 범위

- 범위: Runtime의 항상 로드되는 기본 규칙에 소스 로그 메시지 이모지·이모티콘 금지와 적용 대상을 명시하고 배포 Runtime에 동기화한다.
- 제외 범위: 기존 소스의 일괄 검사·수정, CI·pre-commit·정적 분석기 구현, UI·문서·대화 메시지의 이모지 사용 제한.

### 완료 기준

- 항상 로드되는 Runtime 기본 규칙이 소스 코드의 로그 메시지에는 이모지·이모티콘을 사용하지 않는다는 요구를 명시한다.
- 규칙은 UI·문서·에이전트 대화 등 로그가 아닌 텍스트에 적용되지 않음을 명확히 한다.
- `dist/.mpa/runtime/`가 source Runtime과 동기화되어 설치 대상에도 같은 규칙이 제공된다.

### 사용자 결정

- 로그 이모지·이모티콘 금지는 소스 코드가 남기는 로그 메시지에만 적용한다. 매 수정 시 별도 검사를 자동 실행하지 않는다.

### 변경 불가 제약

- `dist/.mpa/runtime/`는 직접 편집하지 않고 source Runtime 동기화 결과로만 갱신한다.
- Runtime 변경만으로 새 release를 생성하지 않는다.

### 에이전트 가정

| 가정 | 근거 | 틀렸다면 |
|---|---|---|
| 기본 규칙의 적절한 위치는 `core/agent_rules.md`다. | 모든 세션에서 항상 로드되는 Runtime 진입 규칙이다. | 다른 항상 로드되는 규칙이 확인되면 그 위치로 조정하고 계획을 갱신한다. |
