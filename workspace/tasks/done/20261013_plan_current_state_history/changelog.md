## 보완 실행 — 구현·독립 재검증 완료
- 사용자가 독립 검토 지적의 보완을 요청했다. 기존 요구사항 명세·승인해시는 유지한다.
- 파일 내용 비교만으로 교체 경합을 막는 방식을 변경한다. 교체 직전 원본을 복구 기록에 연결된 별도 파일로 먼저 확보하고, 새 내용은 기존 경로를 덮지 않는 생성 방식으로 설치한다. 충돌·중단 시 확보한 파일과 JSON을 보존한다.
- 정상 저장·원복 뒤 plan/changelog와 확보한 원본을 다시 대조하고 일치할 때만 복구 자료를 정리한다. 갱신 중 지원 에이전트는 같은 문서 편집을 직렬화한다.
- 복구 절차의 필수 로드·기존 안내 연결과 발견 섹션의 최상위 배치를 보완한다. 독립 검토 재현을 회귀 테스트에 포함해 재검증한다.
- 실제 구현: guarded_write의 원본 확보·빈 경로 설치를 정상 저장/원복에 적용하고, verify_approval_files로 두 파일과 확보 원본을 대조한다. 충돌·최종 불일치는 자료를 보존하고 복구 필요로 반환한다. 지원 writer 직렬화와 비협조 편집기 지원 한계를 문서화했다.
- 복구 중 plan 경로가 없어도 audit/check/approve/init·gate가 복구 필요를 처리한다. session_start도 존재하는 JSON을 먼저 표시해 필드 초기화·재승인 안내로 잘못 보내지 않는다.
- core의 필수 로드 트리거, detail의 프론트매터/승인 재확인/승인 처리 연결, gate 저장 중단 메시지를 추가했다. 발견 제목은 `## 구현 후 발견`으로 분리하고 minor 생략 참조도 맞췄다.
- 승인 도구 관련 테스트 51개 통과. 교체 직전 원본 편집, 빈 경로 설치 직전 편집, 확보 inode 편집, 이력 저장 후 편집, 원복 설치 직전 편집, plan 경로 없는 복구·gate·세션 안내를 확인했다.
