# 작업 계획서: 수집 이슈 기반 MPA 행동 기준 보완

## 요구사항 명세

### 요청 기준
campingtalk-proj 수집 이슈에서 추린 5가지 MPA 공통 기준을 시스템에 적용·보완한다.

### 목적
질문의 변경 지시 오해, 완료 기록 충돌, 추측성 수정 및 변경 영향 조사 누락을 방지한다.

### 범위·제외 범위
Runtime 지침의 질문 의도 구분, 완료 이동 충돌 방지, 원인 근거 확인, 타입 참조·의존 조사, 기존 구조·연결 제약 확인을 보완하고 dist 동기화 및 기존 source 검증을 수행한다. 관련 7개 이슈는 채택 범위를 한정해 이 작업과 연결·archive한다. hook 구현, 자동 기록 통합·삭제, 프로젝트별 S3·화면 헬퍼·min 정책, 설치 프로젝트 변경 및 release/deploy는 제외한다.

### 완료 기준
5개 기준이 관련 진입 지침에 연결된다. 질문만으로 변경 권한을 만들지 않고 충돌 시 기록을 보존한다. 조사는 관련 작업에만 적용하며 특정 도구나 기존 구현 재사용을 강제하지 않는다. source 확인·관련 기존 테스트·dist 일치 검사에 통과하고 7개 이슈에 채택 범위와 연결 계획을 남긴다.

### 사용자 결정
검토 결과 중 MPA에 적용 가능한 5개 기준의 적용을 2026-11-04 요청했다.

### 변경 불가 제약
기존 사용자 변경과 승인 절차를 보존한다. 승인 범위를 넘는 자동 변경 권한을 추가하지 않는다.

### 에이전트 가정
실행 도구 추가 없이 기존 지침을 보완해 해당 행동 기준을 전달할 수 있다.

### 결정 대기 항목
없음.

### 작업 분류 판단 근거
단일 관심사인 사용자 확정 행동 기준의 지침 보완이다. 적용 방향이 확정되어 새 설계 결정이 필요 없다. 문서 diff로 즉시 복구할 수 있고 외부 서비스 영향이 없다. 추가 취향·가치 판단이 필요 없다.

## 선택 문서
추가 문서 없음. 실행·검증은 이 계획서에서 관리한다.

## 설계 기준
판단 기준은 기존 정본에 두고 설계·구현·완료 진입점에서 참조한다. 관련 상황에서만 조사하며 원인 단정·기존 구조 강제·충돌 기록 자동 병합을 금지한다.

## 실행 계획
기존 변경을 보존하며 관련 지침을 편집한다. 검토·자기 점검과 기존 테스트 후 sync-runtime으로 dist에 동기화한다. 사용자 요청을 근거로 7개 이슈의 제한된 채택 내용을 기록하고 archive한다.

### 생략 항목과 사유
별도 사전 조사·수정 파일 표·예상 조용한 결정·반례·구현 후 발견·검증 결과 문서는 생략한다. 조사와 반례는 기존 대화에서 확정됐고 아래 검증 기준과 실행 기록으로 관리한다.

## 검증 기준
질문/유효 위임 구분, 목적지 충돌/정상 이동, 반증된 가설/근거 부족, 호출 외 타입 참조, 실제 의존 설정, 기존 구조 부적합, 연결 운영 제약 사례를 문구와 대조한다. 관련 정책·계약·INDEX 테스트 및 git diff --check, source/dist 파일 일치, 승인해시 확인을 수행한다.
