수용 이유: 이력 저장과 plan 저장 사이 외부 writer가 changelog를 다시 저장하면 외부 내용은 유지되지만 이번 승인행 없이 성공한다. 이는 plan의 ‘renew-spec이 같은 폴더 changelog에 기록’, ‘변경 전후·이유·명세 영향·승인/증빙 추적’ 완료 기준 및 `agent_rules_detail.md:83-87`의 두 파일 정상 저장 후 journal 제거 계약에 반한다. 외부 내용을 보존하면서도 승인 추적이 끊기므로 P2-1과 다른 결과다.

표현 보정: 요구사항의 정확한 문구는 ‘**저장 오류로** 승인해시와 이력이 어긋나면 실패’이다. R2에는 OSError가 없으므로 그 문구만으로 직접 위반을 증명했다고 하지 않는다. 정상 반환 시 승인 쌍이 이미 불일치하고 복구 근거를 제거한 정상 갱신 계약 위반으로 수용한다. audit 자체의 독립 결함을 추가하지도 않는다. 문서화된 audit 범위는 프론트매터 검사다.
