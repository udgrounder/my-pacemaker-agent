# 작업 계획서: 사용자 소통 언어 일관성 보완

## 요구사항 명세

### 요청 기준
사용자가 한국어 이외 언어로 소통하는 사례를 보고한 뒤, 제시한 개선 기준의 적용을 요청했다.

### 목적
진행 안내·질문·승인·오류·최종 보고의 한국어 기본값과 명시적 언어 요청 우선을 규정하고 독립 실행에도 전달한다.

### 범위·제외 범위
공통 Runtime 규칙, 서브에이전트 공통 전달 기준 및 비평·검증·선택적 위임 진입점의 언어 연결을 보완하고 dist 동기화한다. 코드·식별자·인용 원문과 명시적으로 요청한 외국어 산출물은 보존한다. 외국어 토큰 차단 hook, 설정 schema 추가, 도구 자체 UI 번역, 실제 모델 준수 보장, release/deploy는 제외한다.

### 완료 기준
언어 기준이 항상 로드되는 공통 규칙에 존재한다. 외국어 자료만으로 언어를 바꾸지 않으며 사용자 명시 언어 요청과 산출물 범위를 구분한다. 대화 미상속을 유지하면서 결과 작성 언어를 전달하고 메인은 사용자 언어로 요약한다. 관련 기존 테스트·내용/참조 검사·source/dist 일치·승인 무결성 검사를 통과한다.

### 사용자 결정
직전 제시한 기본 언어·전달 범위·원문/산출물 예외 개선을 “개선작업 진행해줘”로 요청했다.

### 변경 불가 제약
독립 비평·검증의 대화 미상속과 원본 증거·기계 판독 식별자·고정 형식을 유지한다. 사용자 언어 요청을 한국어 기본값보다 우선한다.

### 에이전트 가정
명시적 지침과 출력 전 자기 확인으로 언어 혼입을 줄일 수 있으나 실제 호스트와 모델의 행동 준수까지 보장하지 않는다.

### 결정 대기 항목
없음.

### 작업 분류 판단 근거
단일 관심사인 언어 지침 보완이다. 사용자가 확정한 방향이므로 새 설계 결정이 없고 문서 diff로 즉시 복구 가능하며 외부 연동 변경이 없다. 추가 취향·가치 판단이 필요 없다.

## 선택 문서
추가 문서 없음. 실행·검증은 이 계획서에서 관리한다.

## 설계 기준
언어 기준의 정본은 core/agent_rules.md다. 호출자가 정한 소통 언어·결과 작성 언어·예외만 서브에이전트에 전달하고 구현 대화는 전달하지 않는다. 모든 서브에이전트 호출은 공통 전달 기준을 참조하며 표준 독립 비평·검증의 전달 목록에서도 누락하지 않는다.

## 실행 계획
공통 규칙과 호출 지침을 편집하고 예외 시나리오·관련 참조를 대조한다. 기존 테스트 후 dist 동기화·parity를 확인하고 원래 이슈에 작업과 결과를 연결한다.

### 생략 항목과 사유
별도 사전 조사·예상 조용한 결정·수정 파일 표·반례·검증 결과·구현 후 발견 문서는 생략한다. 대상과 경계는 위 기준에 명시했고 아래 시나리오와 실행 기록으로 검증한다.

## 검증 기준
한국어 대화에 영어 오류/코드 입력, 명시적 영어 소통 요청, 영어 산출물만 요청, 언어 요청 범위 종료 후 복귀, 대화 미상속 독립 실행, 외국어 도구/서브에이전트 결과, 고정 파일명·형식·원문 인용 보존을 문구와 대조한다. 기존 policy_consistency·contract_reference·task_index_policy 검사와 git diff --check, source/dist 파일 내용 일치 및 plan 승인해시를 확인한다.
